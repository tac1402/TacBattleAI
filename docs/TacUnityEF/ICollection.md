---
title: ICollection
---

Интерфейс UnityEF.ICollection используется для отметки класса, который реализует коллекцию и связь один ко многим при объектно-реляционном маппинге. Они перечислены в таблице: 

| Список | Описание |
|--------|----------|
| GDictionary | Глобальный словарь  |
| LDictionary | Локальный словарь  |
| LDictionary_ | Локальный словарь для простых типов |
| LList | Локальный список  |
| LList_ | Локальный список для простых типов |
| LQueue  | Локальная очередь  |
| LQueue_ | Локальная очередь для простых типов  |

Все эти классы поддерживают некоторое общие поведение: 

* При отсутствии модели, реализуют хранение в памяти, соответствующими стандартными реализациями (Dictionary, List, Queue)
* __
