title: ICollection
---

Интерфейс _UnityEF.ICollection_ используется для отметки класса, который реализует коллекцию и связь один ко многим при объектно-реляционном маппинге. Они перечислены в таблице: 

| Коллекция | Описание |
|--------|----------|
| GDictionary<K, V> | Глобальный словарь. V должен быть классом.  |
| LDictionary<K, V> | Локальный словарь. V должен быть классом.  |
| LDictionary_<K, V> | Локальный словарь для простых типов. |
| LList<T> | Локальный список. T должен быть классом.  |
| LList_<T> | Локальный список для простых типов. |
| LQueue<T>  | Локальная очередь. T должен быть классом.  |
| LQueue_<T> | Локальная очередь для простых типов.  |

Все эти классы поддерживают некоторое общие поведение: 
* При отсутствии модели, реализуют хранение в памяти, соответствующими стандартными реализациями (Dictionary, List, Queue)
* __ 

# Разделение на глобальные и локальные коллекции (списки)

* Глобальный список отображается на всю таблицу в БД. Содержит все записи класса (сущности) V из соответствующей таблицы без привязки к какому-либо родительскому объекту. Например, такие единичные классы как Society, обычно содержат списки из всех записей - всех агентов, все здания. Можно разделить по типу в одной иерархии наследования, например, все жилые дома и все компании, а жилые дома и компании наследуются от зданий. Тогда это могут быть разные списки, но ключевое то, что они содержат все записи этого типа (включая наследников по низходящей).
  * Такие коллекции типичны для корневых агрегатов (например, Society может содержать глобальные списки всех агентов, всех зданий и т.д.).
  * Если в иерархии наследования есть базовый класс (например, Building) и наследники (ResidentialBuilding, Company), глобальный словарь может быть построен для базового класса и будет включать все записи всех наследников (полиморфная выборка). В то же время можно создать отдельные глобальные словари для каждого конкретного типа наследника — тогда каждый из них будет содержать только записи соответствующего подтипа (и его наследников по нисходящей).
  * Глобальные словари не требуют внешнего ключа к родительской сущности — они являются корневыми.

* Локальный список может содержать любой подмножество, выборку ...
