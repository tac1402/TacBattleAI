---
title: DataSave
---

Вам нужно включить инструкции для сохранения в общий пакет TacLibrary. Его описание появится в проекте юнити после того как Вы через Unity Package Manager установили пакет TacSave. Далее вам нужно сделать на него ссылку TacLibrary.asmref, рекомендуется следующая структура директорий в проекте:

```csharp
Assets/
  TacLibraryExt/
    Save/
      DataSave.cs
    TacLibrary.asmref 
```
